# Snake Game
A classic Snake game built with Python and Turtle graphics.  
Navigate the snake with arrow keys, eat food to grow, and avoid colliding with the walls or your own tail.

---

# Features
- Smooth movement using Turtle graphics and screen updating
- Dynamic scoreboard
- Food that appears in random locations
- Collision detection (walls + tail)
